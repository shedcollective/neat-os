# Purpose

neat-os is our machine that builds better. It gives every product repository the principles, conventions, playbooks and checks an agent needs to turn a ticket into a reviewed pull request a person can trust without rereading every line. It improves by turning each correction into structure, so the same correction is never needed twice. Every rule here serves one of those aims; a rule that serves neither is a candidate to drop. Anyone can propose a rule; open an issue saying which aim it serves.
