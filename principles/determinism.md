# Determinism

Goal: machines that give tested, trusted results.

Same inputs (repo, skills, ticket) should produce reviewable, comparable output. Scripts and documented steps beat improvised one-offs. Deterministic tools are the source of truth for "green"; agents use them and are not the authority on green themselves.
