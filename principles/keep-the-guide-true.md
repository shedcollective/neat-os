# keep-the-guide-true

A change that invalidates the Agent Guide is incomplete until the guide is updated in the same change. Do not park the correction in IDE-only or host memory.

**Applies when** adding a service, command, env var, pin, or layout fact that `.agents/README.md`, `AGENTS.md`, or a platform leaf currently states; when a pin reason is no longer true.

**The decision it changes.** What is in the pull request. The code change and the guide sentence land together. Session memory, Cursor rules, and host IDE memory are not a substitute for the repository.

**Source.** Recorded in the archive repository.
