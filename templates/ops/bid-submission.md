# Submission

Private operations record only. One file per successful submission version. Never credentials, portal logins, or tokens. Never a full financial or accounts package. The zip is not stored; only the individual redacted files that were sent live beside this page.

| Field | Value |
| --- | --- |
| Date | `<YYYY-MM-DD>` |
| Portal | `<portal>` |
| Reference | `<reference>` |
| Version | `<n>` |
| Zip sha256 | `<sha256 of the zip that was sent; the zip itself is not committed>` |
| Submitted by | `<role>` |
| Status | current |
